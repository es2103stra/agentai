# Анализ вероятности успеха Flash Arbitrage Strategy

## 📊 Реальные шансы успеха

### На Sepolia Testnet (текущая реализация)
- **Вероятность успеха: 70-95%**
- Конкуренция: минимальная (0-2 бота)
- Причина: тестнет, мало участников, нет реальных денег

### На Ethereum Mainnet (продакшен)
- **Вероятность успеха: 15-40%** (зависит от параметров)
- Конкуренция: 5-20 ботов на каждую возможность
- Причина: жёсткая конкуренция, все используют Flashbots

---

## 🎯 Ключевой фактор: Gas Bidding (Priority Fee Escalation)

### Как это работает

```
Обычная транзакция:
  base_fee (1 gwei) + priority_fee (1 gwei) = 2 gwei
  → включается когда угодно, не приоритетно

Flashbots bundle с tip:
  base_fee (1 gwei) + priority_fee (10 gwei) + tip ($50 валидатору)
  → ВКЛЮЧАЕТСЯ ПЕРВЫМ в блоке
```

### Механизм аукциона за блок-позицию

```
Блок #18,547,291
├─ Position 1: Наш бот (tip: $50, priority: 15 gwei) ← ПЕРВЫЕ
├─ Position 2: Конкурент A (tip: $30, priority: 10 gwei)
├─ Position 3: Конкурент B (tip: $20, priority: 8 gwei)
└─ Position 4+: Обычные транзакции
```

**Кто платит больше — тот первый.**

## 📈 Формула вероятности успеха

```python
win_probability = (
    0.30 * latency_factor +      # 30% — скорость подключения
    0.35 * tip_advantage +       # 35% — размер tip vs конкуренты
    0.20 * priority_factor +     # 20% — priority fee
    0.15 * liquidity_factor      # 15% — достаточно ли ликвидности
)

# Корректировка на конкуренцию
if competitors > 0:
    win_probability *= 1 / (1 + competitors * 0.3)
```

### Пример расчёта

**Сценарий: спред 25 bps, 3 конкурента**

```
Latency: 150ms → factor = 0.85
Tip: 1.5% vs avg 2% → advantage = 0.75 / 4 = 0.19
Priority Fee: 12 gwei → factor = 1.0
Liquidity: $5M → factor = 1.0

win_prob = 0.30*0.85 + 0.35*0.19 + 0.20*1.0 + 0.15*1.0
         = 0.255 + 0.067 + 0.20 + 0.15
         = 0.672

# Корректировка на 3 конкурента
win_prob *= 1 / (1 + 3*0.3) = 0.672 / 1.9 = 0.354 (35.4%)
```

**Результат: 35% шанс успеха**

## 💰 Economics: Expected Value

```python
expected_value = (
    win_probability * net_profit -
    (1 - win_probability) * total_cost
)
```

### Пример

```
Net profit (если успешно): $150
Total cost (gas + tip): $45
Win probability: 35%

EV = 0.35 * $150 - 0.65 * $45
   = $52.50 - $29.25
   = $23.25 ✅ Положительный EV → EXECUTE
```

```
Win probability: 20%

EV = 0.20 * $150 - 0.80 * $45
   = $30 - $36
   = -$6 ❌ Отрицательный EV → SKIP
```

## 🚀 Стратегия повышения комиссии

### Уровень 0: Нет конкуренции
```python
priority_fee = 1 gwei
tip = 0.5% от прибыли
→ Минимальные затраты
```

### Уровень 1-3: Умеренная конкуренция
```python
priority_fee = 1 * (1 + 0.5 * 3) = 2.5 gwei
tip = 0.5% * (1 + 0.5 * 2) = 1.0%
→ Повышаем ставку
```

### Уровень 7-10: Жёсткая конкуренция
```python
priority_fee = 1 * (1 + 1.0 * 3) = 4 gwei (или больше)
tip = min(0.5% * (1 + 1.0 * 2), 5%) = 1.5%
→ Максимальная ставка (но не разоряемся)
```

### Потолок: MAX_PRIORITY_FEE_GWEI = 50
```
Даже если конкуренция дикая — не платим больше 50 gwei.
Иначе gas cost съест всю прибыль.
```

## ⚡ Факторы успеха (ранжировано по важности)

### 1. Latency (30% веса)
- **Цель:** < 100ms до Flashbots relay
- **Решение:** VPS в том же дата-центре что relay (AWS us-east-1)
- **Реальность:** 150-300ms → factor 0.7-0.85

### 2. Tip Advantage (35% веса)
- **Цель:** tip > конкурентов
- **Решение:** динамическое повышение tip_percent
- **Реальность:** 0.5-2% от прибыли → factor 0.2-0.8

### 3. Priority Fee (20% веса)
- **Цель:** > 10 gwei
- **Решение:** gas escalation engine
- **Реальность:** 5-15 gwei → factor 0.5-1.0

### 4. Liquidity (15% веса)
- **Цель:** > $1M в пулах
- **Решение:** фильтровать возможности по ликвидности
- **Реальность:** $2-10M → factor 0.8-1.0
